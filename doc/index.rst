SCC
===

SCC is a library providing generic data structures for C.

.. list-table:: Supported data structures
	:header-rows: 1

	* - **Data Structure**
	  - **Type Name**
	* - Bloom Filter
	  - ``scc_bloom``
	* - B-Tree, Associative
	  - ``scc_btmap``
	* - B-Tree, Non-Associative
	  - ``scc_btree``
	* - Double-Ended Queue
	  - ``scc_dequeue``
	* - Hash Table, Associative
	  - ``scc_hashmap``
	* - Hash Table, Non-Associative
	  - ``scc_hashtab``
	* - Red-Black Tree, Associative
	  - ``scc_rbmap``
	* - Red-Black TRee, Non-Associative
	  - ``scc_rbtree``
	* - Stack
	  - ``scc_stack``
	* - Vector
	  - ``scc_vec``
